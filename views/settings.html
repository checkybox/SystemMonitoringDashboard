Agent Registration Code

Use this unique code to register your monitoring agents. This code is permanent and cannot be changed.

Agent Setup:

Set this environment variable when running your agent:

REGISTRATION_CODE=""

Example: REGISTRATION_CODE="A7K4M2P9" node agent.js
